# Changelog - XContest Data Collector

## [2.0.0] - 2024-12-30

### 🎉 Новые возможности

- **Автоматический сбор данных по датам** - главная фича!
  - Настраиваемый диапазон дат (от-до)
  - Фильтры по стране и категории планера
  - Прогресс в реальном времени
  - Возможность остановки/возобновления
  - ~1 дата в секунду (~6 минут на год)

- **Улучшенный UI popup**
  - Раздел "Автосбор данных" с формой настроек
  - Показ прогресса автосбора
  - Даты по умолчанию (последний месяц)
  - Статус в реальном времени

- **Прямые API запросы**
  - Обход ограничения в 10 страниц
  - Запросы напрямую к XContest API
  - Контроль дублей
  - Обработка ошибок

### 🔧 Технические улучшения

- Новый файл `auto-collector.js` - класс для автосбора
- Добавлены разрешения `scripting` и `tabs`
- Новые обработчики сообщений в `background.js`:
  - `START_AUTO_COLLECT`
  - `STOP_AUTO_COLLECT`
  - `GET_AUTO_COLLECT_STATUS`
- Функция `chrome.scripting.executeScript` для выполнения кода на странице

### 📚 Документация

- Новый файл `QUICKSTART.md` - быстрый старт
- Обновлен `README.md` - добавлен раздел об автосборе
- Обновлен `INSTALLATION.md` - инструкции по автосбору
- Новый файл `CHANGELOG.md` - история изменений

### ⚠️ Ограничения версии 2.0

- API возвращает максимум 100 полетов за запрос/дату
- Задержка 1 секунда между запросами (защита сервера)
- Требуется открытая вкладка XContest для работы автосбора

## Миграция с v1.0 на v2.0

**Автоматическая:** Данные в IndexedDB сохраняются при обновлении.

**Действия пользователя:**
1. Перезагрузите расширение в `chrome://extensions/`
2. Обновите страницу XContest (F5)
3. Готово! Автосбор доступен в popup

**Совместимость:** Полная обратная совместимость с v1.0
