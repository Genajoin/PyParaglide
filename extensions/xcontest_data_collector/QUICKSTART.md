# Быстрый старт - XContest Data Collector v2.0

## 📦 Установка (5 минут)

1. Откройте Chrome: `chrome://extensions/`
2. Включите "Режим разработчика"
3. "Загрузить распакованное расширение" → выберите папку `xcontest_data_collector`
4. Готово! Иконка 🎈 появится в панели инструментов

## 🎯 Быстрые сценарии использования

### Сценарий 1: Ручной сбор (просматриваете страницы сами)

1. Откройте https://www.xcontest.org/world/en/flights/
2. Выберите фильтры (страна, категория планера)
3. Переходите по страницам - расширение автоматически сохраняет данные
4. Видите уведомления в правом верхнем углу: "✓ Данные сохранены"

**Когда использовать:** Для небольших объемов (несколько страниц)

---

### Сценарий 2: Автосбор за месяц (рекомендуется)

1. Кликните на иконку расширения 🎈
2. В разделе "Автосбор данных":
   - Дата начала: `2024-06-01`
   - Дата окончания: `2024-06-30`
   - Страна: `SI`
   - Категория: `FAI3`
3. Нажмите "▶️ Начать автосбор"
4. Ждите ~30 секунд
5. Готово! Все полеты за июнь собраны

**Когда использовать:** Для сбора данных за конкретный месяц

---

### Сценарий 3: Автосбор за весь год (массовый сбор)

1. Кликните на иконку расширения 🎈
2. В разделе "Автосбор данных":
   - Дата начала: `2024-01-01`
   - Дата окончания: `2024-12-31`
   - Страна: `SI`
   - Категория: `FAI3`
3. Нажмите "▶️ Начать автосбор"
4. Ждите ~6 минут (365 дней × 1 секунда/день)
5. Следите за прогрессом в popup
6. Готово! Все полеты за год собраны

**Когда использовать:** Для массового сбора данных за большой период

---

### Сценарий 4: Сбор по всему миру (без фильтра страны)

1. Кликните на иконку расширения 🎈
2. В разделе "Автосбор данных":
   - Дата начала: `2024-06-01`
   - Дата окончания: `2024-06-30`
   - Страна: *(оставьте пустым)*
   - Категория: `FAI3`
3. Нажмите "▶️ Начать автосбор"

**Внимание:** Без фильтра страны API может вернуть >100 полетов/день, но берутся только первые 100!

## 📥 Экспорт данных

### Способ 1: Через UI (простой)

1. Кликните на иконку расширения 🎈
2. Нажмите "📥 Экспорт в JSON"
3. Файл `xcontest_flights_2024-12-30.json` будет скачан

### Способ 2: Через консоль (продвинутый)

Откройте консоль (F12) на странице XContest:

```javascript
const openDB = indexedDB.open('XContestFlightsDB', 1);
openDB.onsuccess = function() {
  const db = openDB.result;
  const tx = db.transaction('flights', 'readonly');
  const store = tx.objectStore('flights');
  const all = store.getAll();
  all.onsuccess = function() {
    console.log('Всего полетов:', all.result.length);
    copy(all.result); // Копирует в буфер обмена
  };
};
```

## ⚠️ Важные ограничения

1. **100 полетов/день максимум**
   - API возвращает только первые 100 записей за запрос
   - Используйте фильтры (страна, категория) для уменьшения количества

2. **Задержка между запросами**
   - Автосбор делает паузу 1 секунда между датами
   - Это защищает сервер от перегрузки

3. **Дубли контролируются**
   - Если полет уже есть в БД, он пропускается
   - Безопасно запускать автосбор повторно

## 🐛 Решение проблем

### Автосбор не запускается

**Проблема:** Нажали кнопку, но ничего не происходит

**Решение:**
1. Откройте вкладку с XContest (https://www.xcontest.org)
2. Проверьте консоль background script (`chrome://extensions/` → service worker)
3. Убедитесь что даты заполнены корректно

### Слишком медленно

**Проблема:** Автосбор за год занимает >10 минут

**Решение:**
- Это нормально! 365 дат × 1 сек/дата = ~6 минут + задержки
- Можно остановить и продолжить позже (дубли пропускаются)

### Нет данных после автосбора

**Проблема:** Автосбор завершился, но "Собрано полетов: 0"

**Решение:**
1. Проверьте фильтры - возможно нет полетов с такими параметрами
2. Проверьте консоль на ошибки
3. Попробуйте без фильтров страны/категории

## 💡 Полезные советы

1. **Используйте фильтры**
   - Фильтр по стране ускоряет сбор и уменьшает дубли
   - Категория планера помогает фильтровать PG/HG

2. **Экспортируйте периодически**
   - Экспортируйте JSON после каждого большого сбора
   - Храните бэкапы данных

3. **Следите за прогрессом**
   - Popup показывает прогресс каждые 2 секунды
   - Можно остановить в любой момент

4. **Оптимизация для большого объема**
   - Собирайте по месяцам, а не весь год сразу
   - Используйте узкие фильтры (страна + категория)
