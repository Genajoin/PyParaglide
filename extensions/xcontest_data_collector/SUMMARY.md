# XContest Data Collector v2.0 - Полная документация

## 📦 Что это

Браузерное расширение для Chrome/Edge, которое автоматически собирает данные полетов с XContest.org API для обучения ML моделей.

**Версия:** 2.0.0
**Дата:** 31.12.2025
**Лицензия:** GPL v3
**Проект:** Paraglidable (https://paraglidable.com)

---

## 🎯 Основные возможности

### ✅ Версия 1.0 (базовая)
- Автоматический перехват API запросов при просмотре страниц
- Сохранение в IndexedDB (>5MB поддержка)
- Контроль дублей по flight ID
- Визуальные уведомления
- Экспорт в JSON
- Управление через popup

### 🚀 Версия 2.0 (с автосбором)
- **Автоматический сбор данных по диапазону дат** ⭐ NEW!
- Настраиваемые фильтры (страна, категория планера)
- Прогресс в реальном времени
- Обход ограничения 10 страниц
- ~1 дата в секунду (~6 минут на год)

## 🚀 Быстрый старт

### 1. Установка (5 минут)

```bash
1. Откройте chrome://extensions/
2. Включите "Режим разработчика"
3. "Загрузить распакованное расширение"
4. Выберите папку xcontest_data_collector/
5. Готово! 🎈
```

### 2. Первый запуск автосбора

```bash
1. Кликните на иконку 🎈 расширения
2. В разделе "Автосбор данных":
   - Дата начала: 2024-06-01
   - Дата окончания: 2024-06-30
   - Страна: SI
   - Категория: FAI3
3. Нажмите "▶️ Начать автосбор"
4. Ждите ~30 секунд
5. Готово! Данные за июнь собраны
```

### 3. Экспорт данных

```bash
1. Кликните на иконку 🎈
2. "📥 Экспорт в JSON"
3. Файл xcontest_flights_YYYY-MM-DD.json скачан
```

### Автосбор - как это работает

```javascript
// 1. Пользователь настраивает диапазон дат
startDate = '2024-01-01'
endDate = '2024-12-31'

// 2. AutoCollector перебирает даты
for (currentDate = startDate; currentDate <= endDate; currentDate++) {

  // 3. Формирует API URL
  url = `https://www.xcontest.org/api/data/?flights/world/2024&
         filter[date]=${currentDate}&
         filter[country]=SI&
         filter[detail_glider_catg]=FAI3&
         list[num]=100`

  // 4. Делает fetch запрос через chrome.scripting.executeScript
  response = await fetch(url)
  data = await response.json()

  // 5. Сохраняет в IndexedDB через background.js
  await db.addFlights(data.items)

  // 6. Задержка 1 сек (защита сервера)
  await delay(1000)

  // 7. Обновляет прогресс в popup
  sendProgressUpdate()
}
```

### API запросы

**Формат URL:**
```
https://www.xcontest.org/api/data/?flights/world/{year}&lng=en&
  list[sort]=reg&
  list[start]=0&
  list[num]=100&
  list[dir]=down&
  filter[date]={YYYY-MM-DD}&
  filter[country]={country_code}&
  filter[detail_glider_catg]={category}
```

**Параметры:**
- `year` - год полетов (2024, 2025, etc.)
- `list[num]` - количество записей (максимум 100)
- `filter[date]` - конкретная дата (YYYY-MM-DD)
- `filter[country]` - код страны (SI, FR, AT, etc.)
- `filter[detail_glider_catg]` - категория (FAI1-FAI5)

**Ответ:**
```json
{
  "list": {
    "startItemIndex": 0,
    "numberItemsRequested": 100,
    "numberItemsReturned": 100,
    "numberItems": 150
  },
  "items": [
    {
      "id": 6156451,
      "ident": "Pilot/30.12.2025/09:18",
      "pilot": { "id": 12345, "username": "...", "name": "..." },
      "route": { "distance": 66.617, "points": 65.3 },
      "takeoff": { "name": "..." },
      "glider": { "name": "...", "classFAI": 3 }
    },
    ...
  ]
}
```


2. **Обновить логику** (`popup.js`):
```javascript
const minDistance = document.getElementById('minDistance').value;
if (minDistance) filters.minDistance = minDistance;
```

3. **Обновить AutoCollector** (`auto-collector.js`):
```javascript
if (filters.minDistance) {
  params.append('filter[route_distance]', filters.minDistance);
}
```

### Добавление параллельных запросов

Для ускорения можно обрабатывать несколько дат одновременно:

```javascript
// В auto-collector.js
async processAllDates() {
  const PARALLEL_REQUESTS = 3; // Обрабатывать 3 даты одновременно

  while (this.currentDate <= this.endDate && this.isRunning) {
    const batch = [];
    for (let i = 0; i < PARALLEL_REQUESTS && this.currentDate <= this.endDate; i++) {
      batch.push(this.collectDateData(this.currentDate));
      this.currentDate.setDate(this.currentDate.getDate() + 1);
    }

    await Promise.all(batch);
    await this.delay(1000); // Задержка после батча
  }
}
```

### Формат данных

После экспорта JSON содержит массив полетов:

```json
    "pilot": {...},
    "route": {"distance": 66.617, "points": 65.3},
    "takeoff": {"name": "Khau Pha", "lat": 21.5, "lon": 104.2},
    "glider": {"name": "alpha 3", "classFAI": 3},
    "countries": ["VN"]
  },
  ...

```

### Подготовка для Paraglidable

```python
import json
import pandas as pd

# Загрузка данных
with open('xcontest_flights_2024-12-31.json') as f:
    flights = json.load(f)

# Конвертация в DataFrame
df = pd.DataFrame(flights)

# Извлечение признаков
df['date'] = pd.to_datetime(df['timeClaim']).dt.date
df['hour'] = pd.to_datetime(df['timeClaim']).dt.hour
df['distance'] = df['route'].apply(lambda x: x['distance'])
df['points'] = df['route'].apply(lambda x: x['points'])
df['takeoff_lat'] = df['takeoff'].apply(lambda x: x.get('lat'))
df['takeoff_lon'] = df['takeoff'].apply(lambda x: x.get('lon'))

# Группировка по датам для подсчета активности
activity = df.groupby('date').agg({
    'id': 'count',  # Количество полетов
    'distance': 'mean',  # Средняя дистанция
    'points': 'sum'  # Сумма очков
}).rename(columns={'id': 'flights_count'})

# Сохранение для обучения
activity.to_csv('training_data.csv')
```
